In order to quickly test and move some things in the Airtrack, several short helper scripts are provided.

These scripts solve the following tasks:

- Move the motor to the front and back
- Activate and deactivate the cue LEDs
- Print the coordinates of the platform markers for a linear regression to encounter the camera angle
- Print the coordinates of the platform markers and all center calculations
- Check all core Airtrack functions before using the setup
- Water providing script - to habituate water access in the setup
