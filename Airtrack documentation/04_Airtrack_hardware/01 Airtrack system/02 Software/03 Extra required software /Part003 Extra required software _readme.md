### Hardware part summary overview

To properly work with the Airtrack further software is needed.

1. Matlab (inkl. extra libraries for Basler cameras)
2. Pylon Viewer
3. Arduino IDE

2. Pylon Viewer

Pylon viewer is used to manually check the camera field of views and to configure the cameras. It offers a wide range of settings to adjust like the pixels to use from the sensor, illumination time or the trigger mode.

3. Arduino IDE

In order to apply the Arduino scripts to the Arduino the Arduino IDE is needed. Connect via USB and use the upload function.
